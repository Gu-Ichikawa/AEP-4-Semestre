# AEP-4-Semestre

# 🩸 Plataforma Gamificada para Incentivo à Doação de Sangue

> **AEP — 4º Semestre | 2026**

## 📌 Sobre o projeto

Plataforma web gamificada desenvolvida para incentivar a doação de sangue, facilitando o acesso a informações, locais e campanhas de doação.

O sistema utiliza elementos de gamificação, como pontos, níveis, missões, conquistas e personalização de mascote, buscando aumentar o engajamento dos usuários.

Os dados utilizados sobre hemocentros, campanhas e necessidades de tipos sanguíneos serão simulados e armazenados em banco de dados próprio.

## 🎯 ODS

**ODS 3 — Saúde e Bem-Estar**

O projeto busca contribuir para a conscientização e o incentivo à doação voluntária de sangue.

## 📋 Requisitos

- **RF01 — Cadastro de usuário:** o sistema deve permitir o cadastro de usuários para acesso aos recursos personalizados.

- **RF02 — Gerenciamento do perfil:** o sistema deve permitir que o usuário consulte e atualize seus dados, incluindo seu tipo sanguíneo de forma opcional.

- **RF03 — Consulta de informações:** o sistema deve permitir a consulta de informações sobre o processo e os critérios de doação.

- **RF04 — Consulta de locais e campanhas:** o sistema deve permitir a consulta de locais de doação e campanhas cadastradas.

- **RF05 — Registro de doação:** o sistema deve permitir o registro de uma doação, considerando-a realizada somente após sua confirmação.

- **RF06 — Histórico de participação:** o sistema deve permitir que o usuário consulte seu histórico de doações e participações.

- **RF07 — Missões:** o sistema deve apresentar missões, verificar seus critérios e disponibilizar suas recompensas.

- **RF08 — Pontuação e progressão:** o sistema deve atribuir pontos às atividades válidas e utilizá-los para determinar o nível do usuário.

- **RF09 — Conquistas:** o sistema deve verificar critérios e desbloquear conquistas de acordo com o envolvimento do usuário.

- **RF10 — Mascote:** o sistema deve permitir o acompanhamento da evolução e a personalização do mascote virtual.

- **RF11 — Necessidades simuladas:** o sistema deve apresentar necessidades simuladas de tipos sanguíneos e destacar campanhas relacionadas.

- **RF12 — Administração:** o sistema deve permitir ao administrador gerenciar as informações utilizadas pela plataforma.

- **RF13 — Notificações:** o sistema deve disponibilizar notificações sobre campanhas, missões, conquistas, recompensas, eventos e evolução do mascote.

- **RF14 — Eventos sazonais:** o sistema deve permitir eventos sazonais com missões, conquistas e recompensas temporárias.
